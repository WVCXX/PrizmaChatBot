# Changelog

## 5.0.0
- Добавлены декораторы для аудита ранга, владельца и команд, а также промежуточное ПО для настроек при каждом обновлении.
- Доступ к SQLite разделен на пакет `db`, при этом сохранены импорты `from db import ...`.
- Добавлено отслеживание миграции с помощью `PRAGMA user_version` и синхронизация устаревших версий.
- Добавлены валидаторы входных данных, форматировщики текста и целевые модульные тесты.
- Запись настроек стала атомарной, а аннулирование кэша изменено на время mtime в наносекундах.
- Исправлены эскалация ранга, отрицательные счетчики предупреждений, штрафы за кражу нулевого кошелька, просроченные списки блокировки, переадресация псевдонимов FSM и логирование ограничений скорости.
- Добавлены кнопки «Назад», «Следующий раздел» и «Закрыть» в меню справки.
- Добавлена встроенная пагинация из десяти пунктов для списков администратора, предупреждений, блокировки, репутации и цитат.
- Добавлены одноразовые подтверждения с интервалом в 60 секунд, привязанные к инициатору, для бана, исключения, массового понижения в должности, понижения в статусе и сброса правил.
- Добавлена опциональная клавиатура для ответов модераторов с поддержкой конечного автомата, включающая действия отключения звука, предупреждения, исключения, блокировки и предоставления информации.
- Добавлена настраиваемая задержка удаления для команд службы модерации (`autodelete_service`, по умолчанию 5 секунд; значение 0 отключает её).
- Добавлен предварительный просмотр ID цитат с проверкой разрешений на удаление и сочетание клавиш `?` для ответа whois.
- Добавлена конфигурация pytest и документированная настройка тестовой среды разработки.
